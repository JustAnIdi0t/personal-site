# Personal Website

This repository contains the source code for a personal website built as a
static site and deployed via Netlify.

## Structure

- HTML files correspond to individual pages
- CSS is centralized in a single stylesheet
- No client-side JavaScript is required for core functionality

## Deployment

The site is deployed automatically through Netlify when changes are pushed
to the main branch.

## Content

Site content is intentionally minimal and structured to remain stable over
time. Updates are made by revising existing sections rather than expanding
the site structure.
